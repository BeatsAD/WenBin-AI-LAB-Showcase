## Overview

WenBin AI LAB is Wenbin's personal brand website and a continuously updated public entry point for AI product practice, AI tool exploration, automation workflows, knowledge system building, and personal project showcases.

This repository is a **public showcase repository**. It is used to introduce the project, provide website links, display screenshots, describe the tech stack, and maintain update records.

The full website source code is maintained in a private repository.
