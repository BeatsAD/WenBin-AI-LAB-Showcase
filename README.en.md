# WenBin AI LAB

English | [简体中文](./README.zh-CN.md)

**WenBin AI LAB** is a personal AI lab website for showcasing AI product practice, Agent workflow exploration, knowledge system building, and learning in public.

Website: https://wenbinailab.com

---

## Project Overview

**WenBin AI LAB** is Wenbin's personal brand website and a continuously updated entry point for AI product practice and knowledge system building.

This website is a personal lab for the AI era. It is used to record, organize, and showcase my practical work in AI products, AI tools, automation workflows, knowledge management, and personal project building.

The website mainly focuses on the following areas:

* AI product practice
* Agent workflow exploration
* Knowledge system building
* AI tool usage records
* Learning in public
* Project showcases and milestone outcomes
* Personal AI Lab brand building

---

## Website Positioning

WenBin AI LAB is positioned as:

> A personal AI lab focused on AI product practice, Agent workflows, and knowledge system building.

Its core goal is not simply to showcase “finished works”, but to continuously document how an AI Product Builder learns, builds, ships, and reviews AI products and tools.

The website is designed to carry three types of content:

1. **Project Outcomes**
   Showcasing AI products, tool works, and knowledge system projects that have been organized, can be publicly accessed, or can demonstrate value.

2. **Articles and Thoughts**
   Recording AI tool practice, product building processes, Agent workflows, knowledge system methods, and milestone reviews.

3. **Personal Brand Entry Point**
   Serving as a unified entry point connecting Wenbin’s GitHub, X, website, public projects, and learning content.

## Website Content

WenBin AI LAB currently includes, or plans to include, the following content modules:

### Home

The homepage is used to present personal positioning, website introduction, core directions, and main navigation entries.

Core identity positioning:

> AI Product Builder
> Designing, building, and shipping AI products.
> Learning in public.

### Projects

The projects page is used to showcase AI product outcomes, tool works, and knowledge system projects that have been organized, can be publicly accessed, or can demonstrate value.

Possible project content includes:

* AI product prototypes
* AI tool practice
* Agent workflow cases
* Knowledge base and knowledge system projects
* Automation workflow experiments
* Personal website and public project outcomes

### Articles

The articles page is used to record AI learning, product practice, tool experience, building processes, and milestone reviews.

Possible article topics include:

* AI product building records
* Practical use of tools such as Codex, Cursor, and Claude Code
* Agent workflow research
* Knowledge management methods
* Website building records
* Thoughts on AI programming and product design

### Knowledge Brain

The knowledge system direction is used to accumulate long-term learning content, including AI, product, design, automation, and personal knowledge base building.

## Relationship Between the Public Repository and the Private Source Repository

The source code of the WenBin AI LAB website is maintained in a private repository for actual development, building, and deployment.

This public repository serves only as a project showcase entry point, making it easier to publicly explain the project background, website link, tech stack, and update history on GitHub.

The reasons for this setup are:

* The website can be publicly accessed
* The project introduction can be publicly displayed
* Source code and private configurations can remain secure
* The GitHub profile can showcase the project outcome
* The current Netlify deployment workflow is not affected
