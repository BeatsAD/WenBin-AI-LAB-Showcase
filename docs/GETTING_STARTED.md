## 简体中文

### 访问网站

直接打开 [wenbinailab.com](https://wenbinailab.com)，无需安装应用或配置开发环境。通过当前网站的导航浏览项目、文章与知识内容，具体可用入口以线上页面为准。

### 下载公开资料

在[仓库首页](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase)选择 **Code → Download ZIP**，解压后使用 Markdown 阅读器查看 README。也可以安装 Git 后执行：

```sh
git clone https://github.com/BeatsAD/WenBin-AI-LAB-Showcase.git
cd WenBin-AI-LAB-Showcase
```

打开 `README.zh-CN.md`。图片使用相对路径，请保留 `assets/` 目录。通过 Git 下载的副本在没有本地修改时可用 `git pull --ff-only` 更新；如有本地修改，请先保存自己的工作。

### 本地运行与素材使用

本仓库只有公开说明、图片及协作配置，没有网站应用源码、依赖清单、构建命令或部署脚本，因此不提供本地网站运行或自部署流程。

公开内容可按 [MIT 许可证](../LICENSE)复用，请保留版权和许可声明。封面为 AI 生成的品牌插画；`assets/screenshots/homepage-2026-10-18.png` 为 2026 年 10 月 18 日的在线首页截图，旧展示图也保留在目录中。单次桌面浏览器截图不等于完成跨浏览器或真实设备兼容性验收。

### 遇到问题

- 图片不显示：检查是否完整下载仓库，并使用支持相对图片路径的 Markdown 阅读器。
- 网站无法访问：记录错误、时间、浏览器及网络环境，勿包含密码、Cookie 或个人数据。可换网络或稍后重试。
- 内容或页面问题：通过 [Bug 模板](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase/issues/new?template=bug_report.yml)提交。
- 改进想法：通过[功能建议模板](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase/issues/new?template=feature_request.yml)说明需求。
- 安全问题：按照[安全政策](../SECURITY.md)私密报告。

## English

### Visit the website

Open [wenbinailab.com](https://wenbinailab.com). No application installation or development environment is required. Use the navigation available on the live website to explore projects, articles, and knowledge content.

### Download the public materials

Choose **Code → Download ZIP** on the [repository homepage](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase), extract the archive, and open a README in a Markdown viewer. Alternatively, install Git and run:

```sh
git clone https://github.com/BeatsAD/WenBin-AI-LAB-Showcase.git
cd WenBin-AI-LAB-Showcase
```

Open `README.en.md` and keep the `assets/` directory for relative image paths. A Git checkout with no local changes can be updated using `git pull --ff-only`; save your own work first if it has local modifications.

### Local execution and reuse

This repository contains public documentation, images, and collaboration configuration. It has no website application source, dependency manifest, build commands, or deployment scripts, so it does not provide local website execution or self-hosting instructions.

Reuse public contents under the [MIT License](../LICENSE), retaining the copyright and permission notice. The cover is an AI-generated brand illustration. `assets/screenshots/homepage-2026-10-18.png` captures the live homepage on October 18, 2026; the older showcase image is also retained. A single desktop browser capture does not establish cross-browser or physical-device compatibility.

### Troubleshooting

- Missing images: download the whole repository and use a Markdown viewer supporting relative image paths.
- Website unavailable: record the error, time, browser, and network environment. Exclude passwords, cookies, and personal data. Try another network or try again later.
- Content or page problems: use the [bug report form](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase/issues/new?template=bug_report.yml).
- Improvement ideas: use the [feature request form](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase/issues/new?template=feature_request.yml).
- Security concerns: report privately as described in the [security policy](../SECURITY.md).
