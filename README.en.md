# WenBin AI LAB

WenBin AI LAB is a personal AI lab and public showcase for practical AI product work, workflow experiments, and learning in public.

This repository introduces the lab's direction, project types, and public sharing boundaries.

## Focus

- AI product prototyping and MVP building
- Practical AI workflow experiments
- Learning in public through notes, demos, and project writeups
- Lightweight personal-brand presence for AI product work

## Positioning

WenBin AI LAB is not a large platform, CMS, or community product. It is a focused public entry point for:

- Presenting the lab's direction
- Sharing selected AI product experiments
- Organizing public-facing project materials
- Keeping a clear boundary between public content and private work

## Content Principles

Public materials should be useful, concise, and safe to share.

Do not publish private notes, client information, company-sensitive material, API keys, tokens, passwords, or unpublished project details in this repository.

## Current Status

This repository currently serves as the public introduction repository for WenBin AI LAB.

More project links, screenshots, and showcase materials can be added as the lab evolves.
