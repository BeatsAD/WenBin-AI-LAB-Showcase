## 项目介绍

WenBin AI LAB 是 Wenbin 的个人品牌网站，也是面向 AI 产品实践、Agent 工作流与知识系统构建的个人实验室。它承载项目展示、实践文章、学习记录及个人社交入口，记录一个 AI Product Builder 从学习、构建到交付和复盘的过程。

- **AI 产品实践**：产品原型、工具探索与阶段性项目成果。
- **Agent 工作流**：AI 工具使用、自动化实践与工作流探索。
- **知识系统**：知识管理与长期学习积累。
- **公开学习**：产品构建过程与经验复盘。

本公开仓库包含文档、展示素材与协作配置。网站源码、构建脚本及部署配置保存在独立的私有仓库。下载本仓库不能在本地运行完整网站。

## 安装与使用

使用浏览器访问 **[wenbinailab.com](https://wenbinailab.com)** 即可，无需安装。按当前网站提供的导航浏览内容。

需要下载公开文档与图片时，在 GitHub 选择 **Code → Download ZIP**，或执行：

```sh
git clone https://github.com/BeatsAD/WenBin-AI-LAB-Showcase.git
cd WenBin-AI-LAB-Showcase
```

使用 Markdown 阅读器打开 README，保留相邻的 `assets/` 目录。本仓库没有应用依赖清单或应用构建命令。

详情见[安装与使用指南](./docs/GETTING_STARTED.md)和[兼容性说明](./docs/COMPATIBILITY.md)。
