# Compatibility / 兼容性说明

[Home / 首页](../README.md) · [Getting started / 安装与使用](./GETTING_STARTED.md)

## 简体中文

| 使用场景 | 环境建议 | 验证状态 |
| --- | --- | --- |
| GitHub 阅读文档 | 可访问 GitHub 的现代浏览器 | 可检查文档和图片路径；未完成跨浏览器实测 |
| 本地阅读文档 | Windows、macOS 或 Linux 上支持 UTF-8 和相对图片路径的 Markdown 阅读器 | 无应用运行时依赖；未逐系统验收 |
| 访问在线网站 | 当前稳定版 Chrome、Edge、Firefox 或 Safari | 属于建议环境；未完成浏览器兼容性矩阵验收 |
| 手机或平板访问 | 当前稳定版 Safari（iOS/iPadOS）或 Chrome（Android） | 未完成真实设备与不同屏幕尺寸验收 |
| 本地运行完整网站 | 此公开仓库不提供应用源码 | 不适用 |

本文描述建议环境，不承诺特定浏览器版本、旧版浏览器或内嵌 WebView 的兼容性。网站源码和部署在独立私有仓库维护；这里的检查不等同于线上网站、私有源码或设备验收。

反馈兼容性问题时，请提供页面地址、操作系统和浏览器版本、设备型号或窗口尺寸、复现步骤以及去除敏感信息后的截图。可使用 [Bug 模板](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase/issues/new?template=bug_report.yml)。

## English

| Use case | Recommended environment | Verification status |
| --- | --- | --- |
| Reading on GitHub | A modern browser with access to GitHub | Document and image paths can be checked; no cross-browser test matrix completed |
| Reading locally | A UTF-8 Markdown viewer supporting relative image paths on Windows, macOS, or Linux | No application runtime dependencies; not verified on each OS |
| Visiting the live website | Current stable Chrome, Edge, Firefox, or Safari | Recommended environments; no browser compatibility matrix completed |
| Mobile or tablet access | Current stable Safari on iOS/iPadOS or Chrome on Android | No physical-device or screen-size acceptance completed |
| Running the full website locally | Application source is absent from this public repository | Not applicable |

These are recommendations, not guarantees for specific browser versions, legacy browsers, or embedded WebViews. Website source and deployment are maintained in a separate private repository. Checks here do not establish verification of the live website, private source, or physical devices.

When reporting an issue, include the page URL, OS and browser versions, device model or window size, reproduction steps, and a screenshot with sensitive information removed. Use the [bug report form](https://github.com/BeatsAD/WenBin-AI-LAB-Showcase/issues/new?template=bug_report.yml).
